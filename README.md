# PCIN Paper I — Reproducibility Code and Numerical Outputs

This repository contains the reproducibility code, numerical audits, figures, and machine-readable results accompanying:

**PCIN: Clock-Assisted Hard-Core-Boson Dynamics on Finite Graphs: Graph-Motif-Dependent Effective Interactions and an FCC Realisation**

## Research scope

The accompanying work studies a clock-assisted hard-core-boson Hamiltonian on finite graphs. It develops a third-order Schrieffer–Wolff effective Hamiltonian and examines graph-motif-dependent contributions, clock-parity constraints, and an FCC realisation.

The FCC graph is an assumed geometry in this study. The work does not establish experimental validation, dynamical selection of FCC geometry, or a continuum theory of gravity.

## Repository contents

- Python scripts for finite-graph calculations and numerical audits.
- Clock-parity and cycle-space enumeration.
- Graph-motif validation.
- Numerical results and figures.
- Reproducibility documentation.

## Reproducibility

See the accompanying documentation for software requirements, execution instructions, numerical outputs, and validation procedures.

The numerical checks verify specified identities and calculations over the tested finite graphs. They are not a proof that all possible algebraic errors have been eliminated, nor are they an independent experimental replication.
